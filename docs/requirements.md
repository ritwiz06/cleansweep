# CleanSweep v2 requirements

The acceptance checklist for v2.0 (10-day plan: Day 1 = 2026-10-31, release on Day 10 =
2026-11-09). Each row has the requirement, the test that accepts it, the evidence, and its status.
Phase 8 reruns or opens the evidence of every row and marks it **pass** or **fail**; v2.0 is not
released while any row is open or failing.

Status values: **met** (the acceptance test passed; Phase 8 rechecks it), **partial** (some parts
met, the rest scheduled), **open** (not started).
